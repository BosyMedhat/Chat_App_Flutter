# 💬 Real-Time Chat App

Chat App is a real-time chat application built using **Flutter**, designed to provide a simple and interactive messaging experience.

The app allows users to create an account, log in securely, and exchange messages in a shared chat room.  
It is developed using **Firebase Authentication** for user authentication and **Cloud Firestore** for storing and retrieving messages in real time.

---

## 📝 About the App

Chat App provides a simple chat experience where users can register or log in and start exchanging messages.

The app includes:

- 🔐 User authentication
- 💬 Real-time messaging
- 👤 User identification
- ☁️ Cloud message storage
- ⚡ Real-time message updates

The project combines **Flutter UI development** with Firebase services to provide authentication and real-time communication.

---

## 🚀 Features

- 🔐 **Authentication:** Register and log in using email and password with Firebase Authentication.
- 📝 **Sign Up:** Create a new account using email and password.
- 🔑 **Login:** Sign in to an existing account.
- 💬 **Chat:** Send and receive messages through a shared chat interface.
- ⚡ **Real-Time Messages:** Messages are retrieved and updated in real time using Cloud Firestore.
- 👤 **User Identification:** Messages are associated with the email of the logged-in user.
- ☁️ **Cloud Storage:** Stores chat messages in a Firestore collection.
- 🔄 **Message Updates:** Automatically displays newly added messages without manually refreshing the page.
- ⏳ **Loading Indicator:** Displays a loading state while chat data is being retrieved.
- 🎨 **Custom UI:** Uses custom colors, chat bubbles, buttons, and text fields for the application interface.
